# BioFlyte

> BioFlyte, Inc. is an Albuquerque, New Mexico biodefense instrument company founded in 2020 that
> builds fieldable aerosol time-of-flight mass spectrometers for identifying airborne biological
> and low-volatility chemical threats. Its BioTOF z200 monitors critical infrastructure and its
> MailScreen z200 screens mail and parcels for hazardous powders.
>
> BioFlyte publishes no developer program, no API documentation, no SDK and no pricing. This file
> was GENERATED by API Evangelist from an independent third-party profile — BioFlyte does not
> publish an llms.txt (https://www.bioflyte.com/llms.txt returns 404). Two machine-readable API
> surfaces are reachable without credentials and are described below.

## APIs

- [BioFlyte Content API (WordPress REST wp/v2)](https://www.bioflyte.com/wp-json/wp/v2): Anonymously
  readable. Press releases, the Resources library, marketing pages, a 374-item media library,
  taxonomies and site-wide search. Page with `page`/`per_page` (max 100); read `X-WP-Total` and
  `X-WP-TotalPages`. No OpenAPI is published by BioFlyte; the definition below was derived from
  the live route index at https://www.bioflyte.com/wp-json/.
- [BioFlyte Customer Portal API (AdminWeb)](https://portal.bioflyte.com/): Device fleet, alert,
  location, organization and permission management for deployed BioTOF sensors. **Gated** —
  every operation returns 302 to https://portal.bioflyte.com/identity/account/login for an
  unauthenticated caller. Its OpenAPI 3.0.1 description is served openly at
  https://portal.bioflyte.com/swagger/v1/swagger.json with Swagger UI at
  https://portal.bioflyte.com/swagger/index.html.
